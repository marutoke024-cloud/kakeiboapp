# かけい簿

母（高齢・目が悪い・デジタル機器に不慣れ）のための、生活費の支出管理 PWA。

- 説明なしで感覚的に使えること、文字とボタンが大きいことを最優先
- 1ページのみ・スクロールなし（画面高さ 100dvh に収める）
- データは端末内（localStorage）のみ。ログイン・アカウント登録なし
- オフライン動作。支出のみ（収入は扱わない）

## カテゴリ

生活費 / 水道代 / 電気代 / ガス代 / 携帯代 の5つ（この順で固定）

## 進め方

| 段階 | 内容 | 状態 |
| --- | --- | --- |
| 0 | 画面レイアウト案の提示・確認 | 提示ずみ（`docs/layout-mockup.html`） |
| 1 | 手入力・音声入力・グラフ・月の切り替え・LINE共有 | これから |
| 2 | レシート読み取り（実装方式を検討してから決定） | これから |

## レイアウト案の見かた

`docs/layout-mockup.html` をブラウザで開くと、スマホ画面（360×740px 相当）の
原寸イメージが8画面ならびます。文字とボタンの大きさは実物と同じです。
