# かけい簿

母（高齢・目が悪い・デジタル機器に不慣れ）のための、生活費の支出管理アプリ（PWA）。

- 説明なしで感覚的に使えること、文字とボタンが大きいことを最優先
- 1ページのみ・スクロールなし（画面の高さに必ず収まる）
- データは端末の中だけに保存（ログイン・アカウント登録なし）
- オフラインでも動く。支出だけを記録（収入は扱わない）
- 広告・通知・会員登録・銀行／カード連携はなし

## できること

| 機能 | 内容 |
| --- | --- |
| 手で入力 | 金額欄をひらくと数字キーボードが自動で出る → カテゴリ5つ → 確認 → 保存 |
| 声で入力 | 「5000円」で生活費、「電気代 5000円」でそのカテゴリへ。漢数字（五千円・1万2千円）にも対応 |
| 円グラフ | ドーナツ型。太い内側の輪＝表示中の月、細い外側の輪＝1か月前。まんなかに支出合計 |
| 金額をタップで表示 | 輪かカテゴリ名を押すと、まんなかがその金額に変わる（1か月前の金額も出る）。6秒で自動でもどる |
| 月の切り替え | 「←先月」でさかのぼり、「→今月へ」で戻る。過去の月は青い配色＋「過去の記録」＋見るだけ |
| LINE共有 | 「今月の記録」「年間の記録」の2枚（幅1080px）を作って端末の共有画面をひらく |
| さいごの入力を消す | 「＋」の中にあり、押すと「消しますか？」と確認 |
| 起動アニメーション | 立ち姿のキャラクターの形に色がたまり、0%→100% のメーターが3秒で満ちる |

## レシート読み取りのしくみ

Google Gemini（無料わく）に写真をわたして、**支払った合計金額と種類をひとつだけ**
返してもらいます。候補から選ぶ手間はありません。写真をうつす → 確認する → 保存、の3手です。

1. 写真を長辺1152pxの JPEG にして送る
2. 「合計・お買上計・ご請求金額を選ぶ／小計・お預り・お釣り・ポイントは選ばない」
   という指示と、決まった形（found / amount / category）で返すよう指定する
3. 返ってきた金額と種類を、そのまま確認画面に出す

使うモデルは、そのキーで使える中からいちばん新しい Flash 系を自動で選びます
（`models` の一覧を見て、画像生成・音声・Pro などを外し、版の新しい順に並べて先頭）。
名前が古くなって断られたときは、選びなおして一度だけやり直します。

### はじめて使うとき（ご家族の方の作業・1回だけ）

1. [Google AI Studio](https://aistudio.google.com/apikey) で API キーを作る（無料）
2. アプリの**合計の見出しを1秒ほど長おし**すると「カメラの設定」がひらくので、
   キーを貼りつけて「保存する」。その場でキーが使えるか確かめます

リンクで渡すこともできます。`https://…/?key=APIキー` を一度ひらくと保存され、
アドレスからキーは消えます。キーは端末の中だけに置き、ほかには送りません。

### 気をつけること

- **読み取りのときだけ、レシートの写真が Google に送られます。**
  記録そのもの（金額・カテゴリ・日付）は、これまでどおり端末から出ません
- ネットにつながっていないときは読み取れません（「手で入力する」に案内します）
- 無料わくの1日ぶんを使い切ると、翌日まで読み取れません（その旨を表示します）

## カテゴリ

生活費（食費を含む雑費すべて） / 水道代 / 電気代 / ガス代 / 携帯代 ── この順で固定。

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面の骨組み |
| `styles.css` | 見た目。文字とボタンの大きさは画面の高さに合わせて自動で決まる |

## 文字とボタンの大きさ

画面の高さに合わせて `clamp()` で決めています。いちばん小さい iPhone SE（高さ667px）でも

- 支出合計（円グラフのまんなか） … 46〜58px（けた数に合わせて輪の内側に収まるよう自動で調整）
- カテゴリ名・見出し … 24px以上
- ボタン … 64px以上

画面の下は、右下に「＋」、その上に「送る」、左下にキャラクターという並びです。
キャラクターの大きさは、「＋」「送る」と円グラフの輪に当たらない最大の大きさを
JS が毎回はかって決めています。輪の上下の位置も、余ったすき間が輪の上と下で
半分ずつになるように毎回決めています。

入力のないカテゴリは、輪にも画面にも出しません（共有画像の一覧にだけ
「まだありません」と出ます）。

を下回らず、スクロールも出ないことをブラウザで確認ずみです。

## データの持ち方

`localStorage` の `kakeibo.v1` に、次の形でためています。

```json
{ "entries": [ { "id": "…", "d": "2026-09-20", "c": "life", "a": 1280 } ] }
```

`d` は入力した日（自動で今日）、`c` はカテゴリ、`a` は金額（円）。
端末の外には一切出ません。ホーム画面に追加して使うかぎり、iPhone でも消えません。

カメラの設定は `kakeibo.gemini.key`（APIキー）と `kakeibo.gemini.model`（選ばれたモデル名）に
入れています。こちらも端末の中だけです。

## 動かしかた

このフォルダをそのまま静的ページとして置くだけで動きます（ビルド不要）。

```
python3 -m http.server 8777
```

ホーム画面に追加して使うには **https** で配信する必要があります。
GitHub Pages を使う場合は、リポジトリの Settings → Pages で、このブランチの
ルート（`/`）を公開先に指定してください。
